# Git & GitHub Learning Journey

## 📌 About This Repository

This repository documents my hands-on journey learning Git and GitHub.

I created it while completing the **Git and GitHub Crash Course for Beginners 2026**. Instead of only watching the tutorial, I practiced the commands myself, experimented with different Git workflows, made mistakes, fixed them, and explored how Git tracks changes.

The purpose of this repository is to keep a record of my practice and strengthen my understanding of version control through hands-on learning.

## 📚 What I Practiced

During this learning journey, I practiced:

- Understanding Git, GitHub, and version control
- Understanding local and remote repositories
- Creating local projects and repositories
- Initializing repositories with `git init`
- Creating remote repositories on GitHub
- Cloning repositories with `git clone`
- Checking changes with `git status`
- Staging files with `git add`
- Using different `git add` variations
- Unstaging changes with `git reset`
- Creating commits with meaningful messages
- Configuring Git username and email
- Undoing commits with `git reset HEAD`
- Removing files with `git rm`
- Stopping Git from tracking files with `git rm --cached`
- Viewing commit history with `git log`
- Creating and working with branches
- Switching branches with `git checkout`
- Merging branches
- Resolving merge conflicts
- Checking out previous commits
- Comparing commits with `git diff`
- Understanding `git push`, `git fetch`, and `git pull`
- Pushing local changes to GitHub
- Fetching and pulling remote changes
- Discarding local changes with `git restore`
- Saving unfinished work with `git stash`
- Undoing commits safely with `git revert`
- Rebasing branches with `git rebase`
- Working with pull requests and collaboration

## 💡 What I Learned

One of my biggest takeaways from this course is that Git becomes much easier to understand when I actually use it instead of only watching tutorials.

Through this repository, I practiced making changes, checking what Git sees, staging those changes, committing them, moving between branches, resolving conflicts, and synchronizing my local repository with GitHub.

I also learned that making mistakes while practicing Git is useful because fixing those mistakes helped me understand what the commands actually do.
